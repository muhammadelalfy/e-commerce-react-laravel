تقرير المكوّناتأوفرز · Offers — توثيق تفصيلي لكل مكوّن بُني في الموقع

المشروع: أوفرز · Offers  ·  التقنيات: Next.js 14 · React 18 · TypeScript · GSAP
النطاق: كل مكوّنات الواجهة — شريط التنقّل، الأشرطة الجانبية، التذييل، العناصر المشتركة، وكل الصفحات — مع وصف لكل مكوّن.

0. هيكل التطبيق والتوجيه

App — components/App.tsx

المكوّن الجذر وقلب التطبيق. يحمل كل الحالة العامة ويعمل كموجّه لتطبيق أحادي الصفحة (SPA).

  • الحالة التي يملكها: lang (عربي/إنجليزي، العربية افتراضياً)، theme (فاتح/داكن)، page + param، favs (المفضّلة)، query (البحث).
  • الحفظ: يكتب lang وtheme في localStorage، ويطبّق dir/lang/data-theme على <html>.
  • الموجّه: دالة go(page, id) تبدّل الواجهة وتمرّر للأعلى؛ سلسلة if/else تربط مفتاح الصفحة → مكوّنها.
  • يوفّر السياق: يغلّف كل شيء بـ AppCtx.Provider (النصوص، اللغة، السمة، التنقّل، المفضّلة).
  • يعرض: TopBar ← Header ← main ← Footer.

سياق التطبيق — lib/AppContext.tsx

سياق React باسم AppCtx مع خطّاف useApp(). كل مكوّن يسحب اللغة والسمة والتنقّل والمفضّلة عبره بدل تمرير الخصائص يدوياً.

طبقة البيانات — lib/data.ts

وحدة بيانات ثنائية اللغة مكتوبة النوع: النصوص، الأقسام، المتاجر، المنتجات، المزادات، الإشعارات، الريلز، الفعاليات، الكوبونات، المدن، الباقات، ودالّة money(). جاهزة للربط بخادم دون مسّ الواجهة.

خطّافات حركة GSAP — lib/gsap.ts

  • useReveal — ظهور متدرّج لعناصر الحاوية عند التمرير (ScrollTrigger).
  • useFadeUp — ظهور صعودي لعنصر واحد عند دخوله الشاشة.
  • useMarquee — تمرير أفقي لانهائي متصل؛ يتوقّف عند المرور.
  • useOffersMotion — رسم العروض: حلقات دوّارة، شارة نابضة، وسوم منجرفة، لمعات.
  • الجميع يحترم prefers-reduced-motion.

1. شريط التنقّل (العلوي)

يتكوّن أعلى كل صفحة من شريطين متراكبين.

TopBar — components/Shell.tsx

الشريط الترويجي الرفيع فوق الترويسة (خلفية كحلية).

  • جهة: رقم الهاتف مع أيقونة هاتف.
  • الوسط: الرسالة الترويجية (مثل «خصم حتى ٥٠٪…»).
  • جهة: زر تبديل اللغة (الكرة الأرضية ← عربي⇄إنجليزي) والمدينة الحالية.

Header — components/Shell.tsx

شريط التنقّل الرئيسي الثابت. ينكمش ويكتسب خلفية شفافة ضبابية عند التمرير.

  • Logo — شعار أوفرز؛ النقر عليه يعيد للرئيسية.
  • روابط التنقّل: خصومات أوفرز · مزادات أوفرز · تسوّق مع أوفرز · ريلز · الفعاليات · خريطة المتاجر. الرابط النشط مميّز بلون العلامة.
  • صندوق البحث: بحث حيّ يُرشّح شبكة العروض في الرئيسية.
  • مبدّل السمة: أيقونة شمس/قمر ← فاتح⇄داكن.
  • زر الإشعارات: جرس مع شارة عدد غير المقروء؛ يفتح NotifDropdown.
  • زر المفضّلة: قلب مع شارة العدد المحفوظ ← صفحة المفضّلة.
  • زر الحساب: أيقونة مستخدم ← المصادقة.

NotifDropdown — components/Shell.tsx

اللوحة المنسدلة من الجرس. تعرض آخر ٥ إشعارات (أيقونة النوع، النص، الوقت، نقطة غير مقروء)، وعدد غير المقروء، ورابط «عرض كل الإشعارات».

Logo — components/Shell.tsx

شعار أفقي: أيقونة أوفرز (/logo-icon.svg) بجانب كلمة «أوفرز». يُعاد استخدامه في الترويسة والتذييل ولوحة المصادقة.

2. الأشرطة الجانبية

ثلاثة أشرطة جانبية مميّزة، كل منها عمود فلترة/تنقّل يثبت أعلى الصفحة عند التمرير.

شريط فلترة الأقسام — داخل CategoryPage (Catalog.tsx)

العمود الجانبي في أي صفحة قسم/تسوّق:

  • قائمة الأقسام (في وضع «الكل» فقط) — عبر المكوّن الفرعي VOpt.
  • شريط تمرير نطاق السعر (٠–١٠٠٠ ﷼).
  • فلتر التقييم — الكل / ٣+ / ٤+ / ٤٫٥+ مع معاينة نجوم.
  • قائمة البائعين — الفلترة حسب المتجر.
  • مربّع «العروض الفعّالة فقط».

كل الفلاتر تحدّث شبكة المنتجات فورياً.

شريط لوحة تحكم البائع — داخل Dashboard.tsx

  • كتلة هوية المتجر (شعار المتجر + الاسم + دور «بائع»).
  • أزرار التنقّل: نظرة عامة · المنتجات · الخصومات · الكوبونات · الطلبات · الاشتراك · الإعدادات.
  • زر «عرض المتجر» بالأسفل.

شريط الإدارة — داخل Admin.tsx

  • كتلة هوية الإدارة (درع + «إدارة أوفرز»).
  • أزرار التنقّل: نظرة عامة · المستخدمون · المتاجر · موافقة المنتجات · المدن · الإعلانات · الريلز · الاشتراكات · محتوى التطبيق.
  • زر «خروج» بالأسفل.

3. التذييل (Footer)

Footer — components/Shell.tsx

تذييل الموقع، حاضر في كل صفحة.

  • عمود العلامة: الشعار + الشعار النصّي.
  • أربع مجموعات روابط (ثنائية اللغة، متوافقة مع الاتجاه):
    • أوفرز: عن أوفرز · خصومات · مزادات · ريلز · الفعاليات · خريطة المتاجر
    • للبائعين: أضف متجرك · لوحة التحكم · الأسعار · الدعم
    • المساعدة: الشحن والتوصيل · الإرجاع والاستبدال · الأسئلة الشائعة · تواصل معنا
    • الشركة: الشروط والأحكام · سياسة الخصوصية · المدونة · لوحة الإدارة
  • كل رابط يوجّه عبر go() للصفحة الصحيحة.
  • الشريط السفلي: حقوق النشر + شارات الدفع (Visa · Mastercard · mada · Apple Pay).

5. صفحات العرض (منطقة المحتوى الرئيسية)

5.1 الرئيسية / الخصومات — Home.tsx

  • HeroSlider — ترويسة تدور تلقائياً (٤ شرائح) بأسهم ونقاط؛ صورة منتج في بطاقة بيضاء حادّة + عنوان + زر إجراء.
  • OffersTicker — شريط «عروض ساخنة» أفقي بلا انقطاع (GSAP).
  • QuickFilters — حبّات فلترة سريعة تُرشّح شبكة العروض.
  • الأقسام الشائعة — ٨ أزرار أقسام دائرية.
  • CategoryBanners — شبكة «تسوّق حسب القسم» من ٦ بلاطات (كشف GSAP).
  • شبكة العروض — حبّات + ترتيب + شبكة منتجات (ProductCard).
  • المتاجر المميّزة — شبكة VendorCard.
  • SectionHead — عنوان قسم بخطّ ذهبي + رابط «عرض الكل».
  • OffersMotion — شارة العروض المتحرّكة (GSAP).

5.2 ProductCard — Shell.tsx

بلاطة المنتج الأساسية (الرئيسية، القسم، المتجر، المفضّلة): صورة، لافتة خصم (فعّال أحمر / منتهٍ رمادي)، الاسم، السعر مع الأصلي المشطوب، حبّة البائع، تقييم نجوم، وزر قلب المفضّلة.

5.3 VendorCard — Home.tsx

بطاقة متجر: لافتة + شعار + اسم + تقييم + عدد متابعين. ترتفع عند المرور وتفتح واجهة المتجر.

5.4 كتالوج الأقسام — Catalog.tsx

  • CategoryPage — ترويسة قسم + شريط الفلترة الجانبي + شبكة منتجات قابلة للترتيب/الفلترة + «تصفّح أقساماً أخرى». تخدم أيضاً «التسوّق».
  • VOpt — صف زر اختيار مخصّص لفلاتر الشريط.
  • Vendor — واجهة المتجر: لافتة، شعار، شارة توثيق، التقييم/المتابعون/المدينة/سنة الانضمام، نبذة، شبكة منتجات.

5.5 المزادات — Auctions.tsx

  • Auctions — مزاد مباشر مميّز (مزايدة + عدّاد حيّ + زر) وشبكة بطاقات، كل منها عدّاد حيّ وعدد مزايدات وزر (معطّل عند الانتهاء).
  • Countdown / CountdownLight — عدّادات الساعة:الدقيقة:الثانية (نسختان).

5.6 لوحة تحكم البائع — Dashboard.tsx

  • StatCard — بلاطة مؤشّر (زوار حيّ، مبيعات، خصومات فعّالة، طلبات).
  • جدول المنتجات/الخصومات — مصغّرة، سعر، خصم، حالة، ومفتاح Toggle.
  • OrdersPanel — جدول طلبات بحبّات حالة ملوّنة.
  • CouponsPanel — كوبونات بشريط تقدّم ومفتاح تفعيل.
  • SubscriptionPanel — بطاقات الباقات الثلاث.
  • SettingsPanel — نموذج إعدادات المتجر.
  • AddActivityModal — نافذة «إضافة نشاط جديد» (حقول DField)؛ تدخل «قيد الموافقة».
  • Toggle — مفتاح تشغيل/إيقاف للخصومات والكوبونات.

5.7 لوحة الإدارة — Admin.tsx

  • AdminOverview — مؤشّرات + رسم أعمدة للمبيعات + أعلى الأقسام.
  • AdminApproval — طابور موافقة المنتجات (قبول/رفض).
  • AdminUsers — جدول المستخدمين والبائعين.
  • AdminVendors — شبكة بطاقات المتاجر.
  • AdminCities — شبكة المدن بعدد المتاجر.
  • AdminAds — قائمة الإعلانات/الفعاليات.
  • AdminReels — شبكة إدارة الريلز.
  • AdminSubs — جدول الاشتراكات.
  • AdminContent — صفحات محتوى التطبيق.
  • Head — شريط عنوان اللوحة المشترك.

5.8 صفحات الاكتشاف — Features.tsx

  • Notifications — صفحة إشعارات بعلامات تبويب و«تعليم الكل كمقروء».
  • Reels — بلاطات ريلز عمودية ٩:١٦ (كشف GSAP).
  • Events — بطاقات فعاليات متبادلة بشارات «مباشر».
  • StoresMap — منتقي مدن + قائمة متاجر + خريطة تفاعلية بعلامات.
  • Favorites — شبكة المفضّلة (أو حالة فارغة).
  • PageWrap — غلاف عنوان مشترك لهذه الصفحات.

5.9 المصادقة — Auth.tsx

  • Auth — دخول/تسجيل موحّد للعملاء والبائعين: مبدّل فئة، علامات وضع، نسيان كلمة المرور، أزرار نفاذ/تواصل اجتماعي، توجيه حسب الدور.
  • AField — حقل إدخال معنون بأيقونة أمامية.

5.10 إضافة متجر — AddStore.tsx

  • AddStore — ترويسة تسويقية + خطوات «كيف تبدأ» + نموذج تسجيل؛ ثم شاشة نجاح/قيد الموافقة.
  • SField — حقل إدخال/قائمة معنون.

5.11 الصفحات التعريفية — Info.tsx

  • About — أعمدة أوفرز الأربعة، إحصاءات، زر «أضف متجرك».
  • Pricing — ٣ بطاقات باقات (أساسي/احترافي/متاجر).
  • FAQ — أكورديون الأسئلة الشائعة.
  • Contact — قنوات تواصل + نموذج رسالة بحالة نجاح.
  • Careers — الوظائف المتاحة.
  • Blog — بطاقات مقالات.
  • Legal — الشروط / الخصوصية / الشحن / الإرجاع.
  • PageHead — ترويسة مشتركة لهذه الصفحات.
