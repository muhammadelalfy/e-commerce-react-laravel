# تقرير المكوّنات — أوفرز · Offers
### توثيق تفصيلي لكل مكوّن بُني في الموقع

**المشروع:** أوفرز · Offers (Next.js 14 · React 18 · TypeScript · GSAP)
**النطاق:** كل مكوّنات الواجهة — شريط التنقّل، الأشرطة الجانبية، التذييل، العناصر المشتركة، وكل الصفحات — مع وصف لكل مكوّن.

---

## 0. هيكل التطبيق والتوجيه

### `App` — `components/App.tsx`
المكوّن الجذر وقلب التطبيق. يحمل كل الحالة العامة ويعمل كموجّه لتطبيق أحادي الصفحة (SPA).
- **الحالة التي يملكها:** `lang` (عربي/إنجليزي، العربية افتراضياً)، `theme` (فاتح/داكن)، `page` + `param` (الواجهة الحالية)، `favs` (معرّفات المنتجات المفضّلة)، `query` (نص البحث).
- **الحفظ:** يكتب `lang` و`theme` في `localStorage`؛ وعند التحميل يعيد قراءتهما، ويطبّق `dir`/`lang`/`data-theme` على عنصر `<html>`.
- **الموجّه:** دالة `go(page, id)` تبدّل الواجهة النشطة وتمرّر للأعلى. سلسلة `if/else` تربط مفتاح الصفحة → مكوّن الصفحة المطابق.
- **يوفّر السياق:** يغلّف كل شيء بـ `AppCtx.Provider` ليقرأ أي مكوّن `t` (النصوص)، `lang`، `theme`، `go`، `favs`، `toggleFav`، `toggleLang`، `toggleTheme`.
- **يعرض:** `<TopBar>` ← `<Header>` ← `<main>{الصفحة النشطة}` ← `<Footer>`.

### سياق التطبيق — `lib/AppContext.tsx`
سياق React باسم `AppCtx` مع خطّاف `useApp()`. كل مكوّن يسحب اللغة والسمة والتنقّل والمفضّلة عبر `useApp()` بدل تمرير الخصائص يدوياً.

### طبقة البيانات — `lib/data.ts`
وحدة بيانات ثنائية اللغة مكتوبة النوع: نصوص الواجهة (`STR.ar` / `STR.en`)، الأقسام، المتاجر، المنتجات، المزادات، الإشعارات، الريلز، الفعاليات، الكوبونات، المدن، الباقات، ودالّة التنسيق `money()`. جاهزة للربط بخادم — استبدالها بواجهة برمجية لا يمسّ الواجهة.

### خطّافات حركة GSAP — `lib/gsap.ts`
خطّافات حركة قابلة لإعادة الاستخدام (تحلّ محل تأثيرات CSS الأصلية):
- **`useReveal`** — ظهور متدرّج لعناصر الحاوية عند التمرير (ScrollTrigger).
- **`useFadeUp`** — ظهور صعودي لعنصر واحد عند دخوله الشاشة.
- **`useMarquee`** — تمرير أفقي لانهائي متصل؛ يتوقّف عند التمرير فوقه.
- **`useOffersMotion`** — رسم العروض في الترويسة: حلقات دوّارة، شارة نابضة، وسوم منجرفة، لمعات متلألئة.
- الجميع يحترم `prefers-reduced-motion`.

## 1. شريط التنقّل (العلوي)

يتكوّن أعلى كل صفحة من شريطين متراكبين.

### `TopBar` — `components/Shell.tsx`
الشريط الترويجي الرفيع فوق الترويسة (خلفية كحلية).
- **جهة:** رقم الهاتف مع أيقونة هاتف.
- **الوسط:** الرسالة الترويجية (مثل «خصم حتى ٥٠٪…»).
- **جهة:** زر **تبديل اللغة** (أيقونة الكرة الأرضية ← يبدّل عربي⇄إنجليزي) والمدينة الحالية.

### `Header` — `components/Shell.tsx`
شريط التنقّل الرئيسي الثابت. ينكمش ويكتسب خلفية شفافة ضبابية عند التمرير.
- **`Logo`** — شعار أوفرز (أيقونة SVG) + كلمة «أوفرز»؛ النقر عليه يعيد للرئيسية.
- **روابط التنقّل الرئيسية:** خصومات أوفرز (الرئيسية) · مزادات أوفرز · تسوّق مع أوفرز · ريلز · الفعاليات · خريطة المتاجر. الرابط النشط مميّز بلون العلامة.
- **صندوق البحث:** بحث حيّ عن منتج/متجر يُرشّح شبكة العروض في الرئيسية.
- **مبدّل السمة:** أيقونة شمس/قمر ← يبدّل فاتح⇄داكن.
- **زر الإشعارات:** أيقونة جرس مع شارة عدد غير المقروء؛ يفتح `NotifDropdown`.
- **زر المفضّلة:** أيقونة قلب مع شارة العدد المحفوظ ← يفتح صفحة المفضّلة.
- **زر الحساب:** أيقونة مستخدم ← يفتح المصادقة.

### `NotifDropdown` — `components/Shell.tsx`
اللوحة المنسدلة من أيقونة الجرس. تعرض آخر ٥ إشعارات (أيقونة النوع، النص، الوقت، نقطة غير مقروء)، وعدد غير المقروء، ورابط «عرض كل الإشعارات» لصفحة الإشعارات الكاملة.

### `Logo` — `components/Shell.tsx`
شعار أفقي: أيقونة أوفرز (الحقيبة والنسبة المئوية `/logo-icon.svg`) بجانب كلمة «أوفرز» المنسّقة. يُعاد استخدامه في الترويسة والتذييل ولوحة المصادقة.

## 2. الأشرطة الجانبية

يستخدم الموقع ثلاثة أشرطة جانبية مميّزة، كل منها عمود فلترة/تنقّل يثبت أعلى الصفحة عند التمرير.

### شريط فلترة الأقسام — داخل `CategoryPage` (`components/pages/Catalog.tsx`)
العمود الجانبي في أي صفحة قسم/تسوّق. يحوي:
- **قائمة الأقسام** (في وضع «الكل»/التسوّق فقط) — عبر المكوّن الفرعي `VOpt` (صف اختيار مخصّص).
- **شريط تمرير نطاق السعر** (٠–١٠٠٠ ﷼).
- **فلتر التقييم** — خيارات الكل / ٣+ / ٤+ / ٤٫٥+ مع معاينة نجوم.
- **قائمة البائعين** — الفلترة حسب المتجر.
- **مربّع «العروض الفعّالة فقط».**
كل الفلاتر تحدّث شبكة المنتجات فورياً.

### شريط لوحة تحكم البائع — داخل `Dashboard` (`components/pages/Dashboard.tsx`)
عمود تنقّل صاحب المتجر:
- **كتلة هوية المتجر** (بلاطة شعار المتجر + الاسم + دور «بائع»).
- **أزرار التنقّل:** نظرة عامة · المنتجات · الخصومات · الكوبونات · الطلبات · الاشتراك · الإعدادات — العلامة النشطة مميّزة.
- **زر «عرض المتجر»** بالأسفل ← ينتقل للرئيسية العامة.

### شريط الإدارة — داخل `Admin` (`components/pages/Admin.tsx`)
عمود تنقّل المدير:
- **كتلة هوية الإدارة** (أيقونة درع + «إدارة أوفرز»).
- **أزرار التنقّل:** نظرة عامة · المستخدمون · المتاجر · موافقة المنتجات · المدن · الإعلانات · الريلز · الاشتراكات · محتوى التطبيق.
- **زر «خروج»** بالأسفل.

## 3. التذييل (Footer)

### `Footer` — `components/Shell.tsx`
تذييل الموقع، حاضر في كل صفحة.
- **عمود العلامة:** الشعار `Logo` + الشعار النصّي («وجهتك للعروض والخصومات. سوق متعدد المتاجر.»).
- **أربع مجموعات روابط** (ثنائية اللغة، متوافقة مع الاتجاه):
  - **أوفرز:** عن أوفرز · خصومات أوفرز · مزادات أوفرز · ريلز · الفعاليات · خريطة المتاجر
  - **للبائعين:** أضف متجرك · لوحة التحكم · الأسعار · الدعم
  - **المساعدة:** الشحن والتوصيل · الإرجاع والاستبدال · الأسئلة الشائعة · تواصل معنا
  - **الشركة:** الشروط والأحكام · سياسة الخصوصية · المدونة · لوحة الإدارة
  - كل رابط يوجّه عبر `go()` للصفحة الصحيحة (يتلوّن بلون العلامة عند المرور).
- **الشريط السفلي:** سطر حقوق النشر + شارات الدفع (Visa · Mastercard · mada · Apple Pay).

## 4. العناصر المشتركة — `components/ui.tsx`

لبنات صغيرة يُعاد استخدامها في التطبيق كله.

| المكوّن | الوصف |
|---|---|
| **`Icon`** | مجموعة أيقونات SVG داخلية (~٦٠ أيقونة على شبكة ٢٤: بحث، سلة، قلب، نجمة، متجر، مطرقة مزاد، وسم، جرس…). سُمك الخط والحجم واللون خصائص. |
| **`Stars`** | عرض تقييم بالنجوم (٠–٥ ممتلئة) مع عدد تقييمات اختياري. |
| **`Btn`** | زر بأربعة أنماط (primary / outline / soft / ghost) وثلاثة أحجام (sm / md / lg)؛ يخفت لمعانه عند المرور. |
| **`Thumb`** | مصغّرة منتج — تُظهر الصورة الحقيقية، أو تدرّجاً ملوّناً + رمز القسم كبديل عند غياب الصورة. |
| **`Chip`** | حبّة تبديل تُستخدم لفلاتر الأقسام (حالة نشط/غير نشط). |
| **`money()`** | ينسّق الرقم إلى عملة محلّية (`﷼` بالعربية، `SAR` بالإنجليزية). |

## 5. صفحات العرض (منطقة المحتوى الرئيسية)

### 5.1 الرئيسية / الخصومات — `components/pages/Home.tsx`
صفحة الهبوط (`Home`)، مكوّنة من عدّة مكوّنات فرعية:
- **`HeroSlider`** — ترويسة تدور تلقائياً (٤ شرائح أقسام) بأسهم سابق/تالٍ ونقاط دلالة؛ كل شريحة تعرض صورة منتج في بطاقة بيضاء حادّة + عنواناً + زر إجراء. تتوقّف عند المرور.
- **`OffersTicker`** — شريط «عروض ساخنة» أفقي؛ يتمرّر بلا انقطاع ويتوقّف عند المرور (GSAP `useMarquee`).
- **`QuickFilters`** — حبّات فلترة سريعة (آخر فرص / عروض / ٥٠٪ وأكثر / الجديد) تمرّر إلى شبكة العروض وتُرشّحها.
- **الأقسام الشائعة** — ٨ أزرار أقسام دائرية.
- **`CategoryBanners`** — شبكة «تسوّق حسب القسم» من ٦ بلاطات صور (كشف GSAP عند التمرير).
- **شبكة العروض** — حبّات الأقسام + قائمة الترتيب + شبكة المنتجات المُرشَّحة (تستخدم `ProductCard`).
- **المتاجر المميّزة** — شبكة من `VendorCard`.
- **`SectionHead`** — عنوان قسم قابل لإعادة الاستخدام بخطّ ذهبي سفلي + رابط «عرض الكل» اختياري.
- **`OffersMotion`** — رسم شارة العروض المتحرّكة (GSAP `useOffersMotion`).

### 5.2 `ProductCard` — `components/Shell.tsx`
بلاطة المنتج الأساسية المستخدمة في كل مكان (الرئيسية، القسم، المتجر، المفضّلة). تعرض الصورة، **لافتة خصم** (فعّال = «وفّر X٪ · باقٍ Y أيام» بالأحمر، منتهٍ = رمادي)، الاسم، السعر مع الأصلي المشطوب، حبّة البائع، تقييم النجوم، و**زر قلب المفضّلة**. النقر على البطاقة يفتح المتجر.

### 5.3 `VendorCard` — `components/pages/Home.tsx`
بطاقة متجر: صورة لافتة + بلاطة شعار المتجر + الاسم + التقييم + عدد المتابعين. ترتفع عند المرور؛ تفتح واجهة المتجر.

### 5.4 كتالوج الأقسام — `components/pages/Catalog.tsx`
- **`CategoryPage`** — ترويسة القسم (مسار التنقّل، العنوان، عدد العناصر، صورة منتج عائمة) + **شريط الفلترة الجانبي** (القسم ٢) + شبكة منتجات قابلة للترتيب/الفلترة + شريط «تصفّح أقساماً أخرى». تخدم أيضاً واجهة «التسوّق» (`id="all"`).
- **`VOpt`** — صف زر اختيار مخصّص تستخدمه فلاتر الشريط الجانبي.
- **`Vendor`** — واجهة المتجر: لافتة ملوّنة، شعار المتجر، شارة توثيق، التقييم/المتابعون/المدينة/سنة الانضمام، نبذة، وشبكة منتجات المتجر.

### 5.5 المزادات — `components/pages/Auctions.tsx`
- **`Auctions`** — مزاد مباشر مميّز (المزايدة الحالية + عدّاد حيّ + «زايد الآن») وشبكة بطاقات مزادات، كل منها **عدّاد حيّ** لكل قطعة، وعدد المزايدات، والمزايدة الحالية، وزر مزايدة (معطّل عند الانتهاء).
- **`Countdown` / `CountdownLight`** — عدّادات الساعة:الدقيقة:الثانية (نسخة نصّ داكن ونسخة بيضاء).

### 5.6 لوحة تحكم البائع — `components/pages/Dashboard.tsx`
لوحة تحكم صاحب المتجر: **شريط جانبي** (القسم ٢) + منطقة رئيسية مبوّبة.
- **`StatCard`** — بلاطة مؤشّر (أيقونة، قيمة كبيرة، تسمية، تغيّر) — للإحصاءات (عدّاد زوار حيّ، المبيعات، الخصومات الفعّالة، الطلبات).
- **جدول المنتجات/الخصومات** — كل صف فيه مصغّرة، سعر، نسبة خصم، حالة، ومفتاح **`Toggle`** (تفعيل/إيقاف).
- **`OrdersPanel`** — جدول طلبات المتجر بحبّات حالة ملوّنة.
- **`CouponsPanel`** — بطاقات كوبونات بشريط تقدّم استخدام ومفتاح تفعيل.
- **`SubscriptionPanel`** — بطاقات الباقات الثلاث (الباقة الحالية مميّزة).
- **`SettingsPanel`** — نموذج إعدادات المتجر.
- **`AddActivityModal`** — نافذة «إضافة نشاط جديد» (الاسم، النوع، نسبة الخصم، المدة، الروابط، الوسائط) باستخدام صفوف حقول `DField`؛ العناصر المرسلة تدخل «قيد الموافقة».
- **`Toggle`** — مفتاح التشغيل/الإيقاف المستخدم للخصومات والكوبونات.

### 5.7 لوحة الإدارة — `components/pages/Admin.tsx`
منطقة المدير: **شريط جانبي** (القسم ٢) + ٩ لوحات.
- **`AdminOverview`** — بطاقات مؤشّرات + رسم أعمدة للمبيعات الشهرية + أعمدة أعلى الأقسام.
- **`AdminApproval`** — طابور موافقة المنتجات (قبول ✓ / رفض ✕ لكل صف).
- **`AdminUsers`** — جدول المستخدمين والبائعين بالدور والحالة.
- **`AdminVendors`** — شبكة بطاقات المتاجر.
- **`AdminCities`** — شبكة المدن بعدد المتاجر.
- **`AdminAds`** — قائمة الإعلانات/الفعاليات بشارات «مباشر».
- **`AdminReels`** — شبكة إدارة الريلز (قبول/رفض).
- **`AdminSubs`** — جدول الاشتراكات.
- **`AdminContent`** — صفحات محتوى التطبيق (روابط تحرير).
- **`Head`** — شريط عنوان اللوحة المشترك مع زر إجراء اختياري.

### 5.8 صفحات الاكتشاف — `components/pages/Features.tsx`
- **`Notifications`** — صفحة إشعارات كاملة بعلامات تبويب (الكل / غير مقروء / بائعين / عملاء) و«تعليم الكل كمقروء».
- **`Reels`** — بلاطات ريلز عمودية ٩:١٦ (أيقونة تشغيل، عدد مشاهدات، بائع، وصف، زر إعجاب، شارة «قيد المراجعة») — كشف GSAP عند التمرير.
- **`Events`** — بطاقات فعاليات متبادلة (صورة، تاريخ، مدينة، وصف، شارة «مباشر»، زر إجراء).
- **`StoresMap`** — منتقي المدن + قائمة متاجر المدينة (بالمسافة) + خريطة تفاعلية بعلامات تعرض عدد متاجر كل مدينة.
- **`Favorites`** — شبكة المنتجات المفضّلة (أو حالة فارغة مع زر إجراء).
- **`PageWrap`** — غلاف عنوان/عنوان فرعي مشترك لهذه الصفحات.

### 5.9 المصادقة — `components/pages/Auth.tsx`
- **`Auth`** — دخول/تسجيل موحّد للعملاء والبائعين: لوحة علامة + لوحة نموذج بمبدّل الفئة (عميل/بائع)، وعلامات وضع (دخول/تسجيل)، وتدفّق نسيان كلمة المرور، وأزرار نفاذ/تواصل اجتماعي، وتوجيه حسب الدور عند الإرسال.
- **`AField`** — حقل إدخال معنون بأيقونة أمامية (لكل حقول المصادقة).

### 5.10 إضافة متجر (تسجيل البائع) — `components/pages/AddStore.tsx`
- **`AddStore`** — ترويسة تسويقية (المزايا) + قائمة «كيف تبدأ» من ٣ خطوات + نموذج تسجيل؛ عند الإرسال تظهر شاشة نجاح/قيد الموافقة.
- **`SField`** — حقل إدخال/قائمة معنون مستخدم في نموذج التسجيل.

### 5.11 الصفحات التعريفية — `components/pages/Info.tsx`
يوجّهها `Info` حسب معرّف الصفحة:
- **`About`** — أعمدة أوفرز الأربعة، إحصاءات، وزر «أضف متجرك».
- **`Pricing`** — ٣ بطاقات باقات للبائع (أساسي / احترافي / متاجر)، الاحترافي مميّز.
- **`FAQ`** — أكورديون الأسئلة الشائعة.
- **`Contact`** — قنوات التواصل + نموذج رسالة بحالة نجاح «تم الإرسال» (حقول `CField`).
- **`Careers`** — الوظائف المتاحة.
- **`Blog`** — بطاقات مقالات المدونة.
- **`Legal`** — مقالات الشروط / الخصوصية / الشحن / الإرجاع (أقسام مرقّمة).
- **`PageHead`** — ترويسة مشتركة (مسار تنقّل + عنوان + عنوان فرعي) لهذه الصفحات.
