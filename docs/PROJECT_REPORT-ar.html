2.2 القدرات الأساسية

  • ✅ عربي أولاً وثنائي اللغة بالكامل مع انعكاس تام للاتجاهين.
  • ✅ سمة فاتحة وداكنة، محفوظة في localStorage، دون وميض عند التحميل.
  • ✅ تنقّل داخلي (SPA) يحاكي نموذج التنقّل الأصلي بانتقالات فورية.
  • ✅ ميزات تفاعلية حيّة — عدّادات ومزايدة، مفضّلة، فلاتر، ترتيب، بحث، مفاتيح كوبونات/خصومات، موافقة منتجات، عدّاد زوّار حيّ.
  • ✅ صور علامة حقيقية مربوطة بالأقسام والمنتجات.

2.3 حركة GSAP (المكتبة المطلوبة)

تم استبدال تأثيرات CSS @keyframes بحركة تعتمد على GSAP (lib/gsap.ts):

  • رسم العروض في الترويسة — حلقات دوّارة، شارة «٪» نابضة، وسوم خصم منجرفة، ولمعات متلألئة.
  • شريط العروض الساخنة — تمرير لانهائي متصل، يتوقّف عند التمرير فوقه.
  • كشف عند التمرير — ظهور متدرّج للعروض والمتاجر والريلز عبر ScrollTrigger.
  • يحترم prefers-reduced-motion (تقليل الحركة).

7. القيود المعروفة / الخطوات التالية

  • لا يوجد خادم خلفي بعد — المصادقة والمدفوعات وتخزين الكتالوج والمزادات اللحظية واجهات مكتملة تجريبياً؛ طبقة البيانات جاهزة للربط.
  • الإشعارات الفورية (FCM) — نموذج الإشعارات موجود؛ ربطه بخدمة حقيقية مهمّة مستقبلية.
  • شعار الترويسة — أيقونة أوفرز الأصلية + كلمة أوفرز؛ الأصول متوفّرة في public/.
  • المدفوعات — مدى/Apple Pay/Visa تظهر كشارات؛ الدفع الحقيقي يتطلّب تكامل مزوّد دفع.

8. الخلاصة

إعادة بناء كاملة لسوق «أوفرز» بلغة Next.js — ثنائية اللغة، بسمات، وحركة GSAP — تشمل الواجهات الـ١٥ وصوراً حقيقية للعلامة، مُتحقَّق منها وتعمل بلا أخطاء. الشيفرة مكتوبة النوع، مقسّمة إلى مكوّنات، وجاهزة للربط بخادم.
