## 1. الهدف
استيراد تصميم سوق «أوفرز» من مشروع Claude Design وإعادة بنائه كتطبيق ويب احترافي بلغة **Next.js**، باستخدام مكتبة الحركة **GSAP**، مع الصور الحقيقية للعلامة من ملف Figma «Store mobile app».

## 2. ما تم تسليمه

### 2.1 تطبيق كامل — ١٥ واجهة
| المجال | الواجهات |
|---|---|
| **واجهة المتجر** | الرئيسية/الخصومات، كتالوج الأقسام، واجهة المتجر، التسوّق |
| **المزادات** | مزادات مباشرة مع عدّادات ومزايدة |
| **الاكتشاف** | ريلز، فعاليات وإعلانات، خريطة المتاجر، المفضّلة، الإشعارات |
| **الحسابات** | المصادقة (عميل + بائع)، تسجيل إضافة متجر |
| **البائع** | لوحة التحكم (نظرة عامة، منتجات، خصومات، كوبونات، طلبات، اشتراك، إعدادات) |
| **الإدارة** | لوحة إدارة (نظرة عامة، مستخدمون، متاجر، موافقات، مدن، إعلانات، ريلز، اشتراكات، محتوى) |
| **تعريفية** | من نحن، الأسعار، الأسئلة الشائعة، تواصل معنا، الوظائف، المدونة، القانونية (الشروط/الخصوصية/الشحن/الإرجاع) |

### 2.2 القدرات الأساسية
- ✅ **عربي أولاً وثنائي اللغة بالكامل** مع انعكاس تام للاتجاهين.
- ✅ **سمة فاتحة وداكنة**، محفوظة في `localStorage`، دون وميض للسمة عند التحميل.
- ✅ **تنقّل داخلي (SPA)** يحاكي نموذج التنقّل الأصلي بانتقالات فورية.
- ✅ **ميزات تفاعلية حيّة** — عدّادات ومزايدة المزادات، المفضّلة، الفلاتر، الترتيب، البحث، مفاتيح الكوبونات/الخصومات، تدفّق موافقة المنتجات، عدّاد الزوّار الحيّ.
- ✅ **صور علامة حقيقية** مربوطة بالأقسام والمنتجات.

### 2.3 حركة GSAP (المكتبة المطلوبة)
تم استبدال تأثيرات CSS `@keyframes` الأصلية بحركة تعتمد على **GSAP 3 + ScrollTrigger**، مُجمّعة في وحدة خطّافات قابلة لإعادة الاستخدام (`lib/gsap.ts`). GSAP و ScrollTrigger يُسجّلان مرّة واحدة على العميل مع إعدادات آمنة (`nullTargetWarn: false`، `ignoreMobileResize`).

**الخطّافات (Hooks):**
| الخطّاف | الوظيفة |
|---|---|
| `useHeroImage` | أنيميشن دخول صورة الشريط (تكبير مرن `back.out` + توهّج نابض) عند كل شريحة، مع ضمان بقاء الصورة ظاهرة. |
| `useOffersMotion` | رسم العروض في الترويسة — حلقات دوّارة، شارة «٪» نابضة، وسوم خصم منجرفة، لمعات متلألئة. |
| `useMarquee` | شريط «عروض ساخنة» بتمرير لانهائي متصل، يتوقّف عند التمرير فوقه. |
| `useReveal` | ظهور متدرّج (fade + rise) لعناصر شبكة عند دخولها الشاشة. |
| `useAutoReveal` | **كشف تلقائي لكل الموقع** — مربوط بـ `<main>`، يمسح كل قسم/بطاقة/شبكة في أي صفحة ويُظهرها عند التمرير، ويُعاد المسح عند كل تنقّل. |
| `useParallax` | انزلاق رأسي مرتبط بموضع التمرير (scrub) للصور/اللافتات. |
| `useScrubReveal` | ظهور مرتبط بتقدّم التمرير (stagger). |

- كل الحركات تستخدم `fromTo` لضمان الحالة النهائية (لا تعلق العناصر مخفية).
- الجميع يحترم `prefers-reduced-motion` (تعطيل الحركة).
- **إضافة GSAP الرسمية** (`greensock/gsap-skills`) مُثبّتة في بيئة Claude Code لتوجيه أفضل لاستخدام GSAP.

## 3. الأصول — دمج الصور الحقيقية
تم استيراد ٣١ صورة حقيقية من ملف Figma «Store mobile app» المُنزَّل وربطها في التطبيق (`public/img/`):

| القسم في التطبيق | الصورة |
|---|---|
| إلكترونيات | سماعات رأس |
| العطور/الجمال | أحمر شفاه |
| الأزياء | قميص بولو |
| المطاعم | طبق طعام |
| الكتب | دفتر |
| الأثاث والأجهزة | غسّالة |
| المنتجات | مضرب، مستحضرات، أدوات مكتبية |

إضافةً إلى ٨ صور أقسام إضافية (سيارات، رياضة، ألعاب، أطفال، حيوانات أليفة، مكتب، أدوات منزلية، طعام منزلي) وأيقونة العلامة الأصلية.

ولأن هذه صور كتالوج بخلفية بيضاء (بينما افترض التصميم صوراً تحريرية داكنة)، أُعيد تنسيق **الترويسة وبطاقات الأقسام وترويسة صفحة القسم** لعرضها بشكل نظيف (ألواح فاتحة / احتواء)، وضُبط تحجيم صورة الترويسة لتُعرض بحجم قريب من الأصل (**بلا ضبابية**).

## 4. البنية المعمارية
```
mashhoor-next/
├── app/                # موجّه Next.js: layout.tsx, page.tsx, globals.css (متغيّرات التصميم)
├── components/
│   ├── App.tsx         # الحالة + موجّه SPA (السمة، اللغة، الصفحة، المفضّلة)
│   ├── Shell.tsx       # الشريط العلوي، الترويسة، التذييل، بطاقة المنتج
│   ├── ui.tsx          # الأيقونات، النجوم، الأزرار، Thumb، Chip، money()
│   └── pages/          # الرئيسية، الكتالوج، المزادات، اللوحة، الإدارة، المصادقة، إضافة متجر، تعريفية، ميزات
├── lib/
│   ├── data.ts         # بيانات ثنائية اللغة مكتوبة النوع (نصوص، أقسام، متاجر، منتجات، مزادات…)
│   ├── AppContext.tsx  # سياق حالة التطبيق
│   └── gsap.ts         # خطّافات GSAP قابلة لإعادة الاستخدام (كشف، شريط متحرّك، حركة العروض)
├── public/img/         # صور المنتجات والأقسام الحقيقية
└── docs/               # SRS-ar.md, PROJECT_REPORT-ar.md
```
- TypeScript صارم مع مسارات `@/`.
- طبقة البيانات معزولة في `lib/data.ts` → جاهزة للربط بواجهة برمجية (استبدالها بـ REST/GraphQL دون تغيير الواجهة).

## 7. القيود المعروفة / الخطوات التالية
