## 1. الهوية والعلامة التجارية

### 1.1 تغيير الاسم إلى «أوفرز»
- استُبدل اسم «مشهور / Mashhoor» بـ **«أوفرز / Offers»** في كامل الموقع (الشعار، شريط التنقّل، النصوص، عنوان الصفحة، المزادات، الإدارة…).

### 1.2 الشعار الجديد + اشتقاق الألوان منه
- تم استبدال الشعار القديم بشعار **OFFERZ · اوفرز** الرسمي.
- **تكبير الشعار** إلى 58px (سطح المكتب) / 46px (جوّال).
- **لوحة ألوان جديدة مشتقّة من بكسل الشعار:**
  - الأساسي: وردي/ماجنتا `#c83260`
  - الحبر والخلفيات الداكنة: كحلي‑تركوازي `#1e404b`
  - خلفية الصفحة: رمادي وردي دافئ `#f4f1f3`
  - أُعيد اشتقاق الوضع الداكن كاملاً (وردي أفتح + خلفية كحلية `#0e1519`).

## 2. تجربة المستخدم والتجاوب

### 2.1 موقع متجاوب بالكامل
- طبقة CSS متجاوبة شاملة عبر ثلاث نقاط توقّف (١٠٢٤ / ٧٦٨ / ٥٦٠).
- **قائمة برجر (burger)** للجوّال بدل شريط التنقّل، مع لوحة منسدلة وبحث.
- تكيّف الشبكات (٤→٢→عمود)، والأشرطة الجانبية، والترويسة، والتذييل، والشريط الرئيسي.

### 2.2 نافذة اختيار الدولة عند التحميل
- تظهر مرّة واحدة عند أول زيارة، بقائمة منسدلة **لدول الخليج بالعربية** + أعلام، وتُحفظ في `localStorage`.

### 2.3 تحسينات الشريط الرئيسي (Hero)
- تحويل الشريط ليعرض **المتاجر (البائعين)** بدل المنتجات، مع التقييم والمدينة والمتابعين وزر «زيارة المتجر».
- تكبير صورة الشريط + توهّج متدرّج + إصلاح الضبابية (تصغير بدل تكبير).
- **إسراع انتقال الشرائح على الجوّال** (0.3s بدل 0.7s).
- إصلاح تداخل النص مع الأسهم، وضبط النقاط (bullets).

## 3. حركة GSAP الموسّعة

- تسجيل ScrollTrigger بإعدادات آمنة.
- **خطّافات حركة متنوّعة جديدة:** `useZoomIn` (تكبير)، `useFlipIn` (قلب ثلاثي الأبعاد)، `useSlideIn` (انزلاق جانبي يحترم RTL)، `useBlurIn` (ضبابية)، `useBatchReveal` (مجموعات)، `useParallax`، `useScrubReveal`.
- **كشف تلقائي لكل الموقع عند التمرير** عبر `useAutoReveal` المربوط بـ `<main>`.
- إصلاح خلل بقاء العناصر مخفية (تحويل `from` إلى `fromTo`).
- تثبيت إضافة GSAP الرسمية `greensock/gsap-skills` في بيئة Claude Code.

## 4. الأدوار والصلاحيات (نمط Spatie)

- **مستخدم «مشهور» — ناشر ريلز فقط:** تبويب ثالث في المصادقة (عميل · تاجر · **مشهور**)، يُوجّه إلى **استوديو الريلز** بدور `reels`، ويمكنه **إضافة ريلز فقط** مع بوّابة صلاحيات.
- **إدارة الأدوار والصلاحيات (CRUD كامل):** تبويب في لوحة الإدارة على نمط Spatie:
  - أدوار (admin/vendor/reels/customer) مع الحارس (guard) وعدد المستخدمين.
  - إنشاء/تعديل/حذف الأدوار، وتعيين الصلاحيات مجمّعة مع «تحديد الكل».
  - صلاحيات بصيغة `action.subject`، إضافة/حذف.
  - **معرّبة بالكامل** (أسماء الأدوار والصلاحيات والمجموعات) مع إبقاء المفاتيح التقنية بالإنجليزية.

## 5. قسم العقارات

- إضافة قسم **العقارات (Real Estate)** بأيقونة مبنى جديدة.
- يظهر في: **الأقسام الشائعة**، **الشريط الجانبي للتصفية**، **الإعلانات/الفعاليات** (معرض العقارات).
- متجر عقاري («ديار العقارية») + ٣ عروض عقارية (فيلا، شقة، أرض) لجعله قابلاً للتصفّح.
- إصلاح لون عنوان صفحة القسم ليظهر في الوضعين الفاتح والداكن (طبقة تعتيم + ظل نصّي).

---

## 6. لوحة الإدارة — إضافات

- **تفعيل نوافذ «إضافة جديد»** التي كانت معطّلة: المستخدمون، المدن، الإعلانات — عبر مكوّن نافذة مشترك `AdminModal` مع إضافة/حذف فعلي.
- **إدارة الدول (Countries CRUD):** تبويب جديد بدول الخليج (علم + رمز الاتصال)، إضافة/حذف.
- **إصلاح بق النافذة المغطّاة بالشريط الجانبي:** عرض النوافذ عبر **React Portal** إلى `document.body` مع رفع z-index إلى 1000.

## 7. لوحة تحكم التاجر — إضافات

- **السجل التجاري في تسجيل المتجر:** حقل **رقم السجل التجاري** + **رفع ملف مصادقة من الغرفة التجارية** (PDF/صورة) — أُضيف في نموذج «أضف متجرك» **وفي** تبويب تسجيل التاجر بصفحة المصادقة.
- **مواقع متعددة للمتجر:** تبويب **«مواقع المتجر»** بلوحة تحكم التاجر — خريطة تفاعلية، إضافة **أكثر من فرع/موقع** (بالضغط على الخريطة أو عبر نافذة)، مع الحذف.
